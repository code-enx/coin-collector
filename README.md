# Coin Collector

A simple 2D collection game built with **Godot Engine**. Collect all the carrots before time runs out!

## About the Game

Coin Collector is a small game development project created to learn and practice game mechanics, player movement, collision detection, UI design, audio, and scene management in Godot.

### Features

- 2D player movement
- Sprinting mechanic
- Animated collectibles
- Collection counter
- Countdown timer
- Victory and game-over screens
- Background music and sound effects
- Restart and quit options

## Controls

| Key | Action |
|---|---|
| Arrow keys | Move the player |
| Shift | Sprint |

## How to Play

1. Move around the game world.
2. Collect all the carrots.
3. Keep an eye on the countdown timer.
4. Collect every carrot before time runs out to win.
5. If time runs out first, the game ends.
6. Restart to play again.

## Built With

- **Engine:** Godot Engine 4
- **Language:** GDScript
- **Platform:** Linux
